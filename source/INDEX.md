## Что из материалов следует для проекта

- Приложение — вкладка в карточке смарт-процесса **Сделки** (`entityTypeId = 1038`); данные — модули (`entityTypeId = 1050`, фильтр `PARENT_ID_1038 = <сделка>`), сгруппированные по этапам (`entityTypeId = 1042`, `PARENT_ID_1042` у модуля).
- Пересчёт дат стадий делает БП на портале; приложение читает/пишет поля: даты Рассмотрение/Разработка и 4 длительности (Запуск, Корректировка, Ожидание, Согласование).
- «Дата начала работ» = дата завершения Рассмотрения, «дата завершения работ» = дата Разработки — основной акцент на Ганте; остальные стадии — вторичный акцент.
- В таблице нужны вложенные группы «этап → модули», сворачивание этапа, сортировка по колонкам, масштаб Ганта 1 день–4 недели, «смещение» первой даты календаря.
