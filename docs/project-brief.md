## Технические параметры

| Параметр | Значение |
|----------|----------|
| Хостинг | prod *(см. `.deploy-target`)*, slug: `rdi-module-plan` |

| Скоупы Б24 | crm user placement department |

| Cron | нет (`www/bin/process.php` удалён) |
| Особенности | Данные: смарты Сделки 1038 / Этапы 1042 / Модули 1050; пересчёт дат стадий делает БП на портале, приложение только читает/пишет поля дат и длительностей |
