Контракт парсера дат (п.3) — в `parseDyy` (`gantt-logic.js`):
- `ДД.ММ.ГГ`, `ДД-ММ-ГГ`, `ДДММГГ` → ISO `ГГГГ-ММ-ДД` (2000+ГГ), проверка
  валидности даты (как сейчас: день/месяц совпадают с распарсенной датой), иначе null;
- `ДД.ММ`, `ДД-ММ`, `ДДММ` → ISO с ТЕКУЩИМ годом, та же проверка валидности;
- пустое/непохожее → null. Формат поля при рендере остаётся `ДД.ММ.ГГ` (`fmtDyy`).

Контракт смещения (п.10): offset всегда = `defaultOffsetIso(bounds.min, state.step)`
при загрузке и при клике по scale-кнопке; ручной ввод в `offsetInput` —
переопределение до следующего переключения масштаба/перезагрузки.

Правила кода: без комментариев в коде, REST не трогаем, state/changelog не пишем
(журнал — отдельным шагом после живой проверки).
