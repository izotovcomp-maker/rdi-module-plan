## Порядок и зависимости

- M1→M2→(M3, M4 параллельно)→M5→M6→M7→M8. Макет согласует человек (M8).
- После M8: пересмотр плана/прав, затем B1→B2→B4 (B3, B5 — рядом), затем D1→D2.
- D2 (реальный деплой) — только по явной команде человека и после согласования макета.

## Верификация плана (junior-тест)

- Каждая задача имеет точные файлы и проверку; суждений «по вкусу» нет.
- YAGNI: нет кэша, черновиков, истории правок, создания сущностей — по не-целям дизайна.
