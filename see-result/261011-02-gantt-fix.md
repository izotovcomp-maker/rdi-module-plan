# Фикс читаемости Ганта в макете (по снимку see-result/261011-01.md)

## Диагноз (по коду mock/mock.js, css/mock.css, скриншоту)

1. **Полосы Ганта не видны без горизонтального скролла** — главная причина.
   Лид-колонки таблицы занимают ≈840px (`minmax(280px,340px)` + 56 + 96×3 + 56×3),
   COL_W=40px → на экране остаётся 1–2 колонки календаря, все полосы за скроллом.
2. **Даты обрезаны** («07.09.2□»): нативный date-input ≈90px не влезает в колонку
   96px минус padding 20px.
3. **Стартовый вид не показывает работу**: нет авто-прокрутки к полосам.
4. **Плашка устарела**: текст «Проверяем каркас (M2)…» остался от ранней версии.

## Правки

### mock/mock.js

1. `const COL_W = 40;` → `48`.
2. `setGridCols()` — компактнее:
   ```js
   const lead = state.mode === 'group' ? '30px ' : '';
   document.documentElement.style.setProperty('--grid-cols',
     lead + 'minmax(200px, 250px) 44px 100px 100px 100px 46px 46px 46px repeat(' + nCols + ', ' + COL_W + 'px)');
   ```
   (даты 100px, числа 44–46px, имя 200–250px).
3. Авто-прокрутка к полосам после `render()` (НЕ после каждого keystroke):
   ```js
   let hScrolledByUser = false;
   function ensureBarsVisible(bounds) {
     if (hScrolledByUser || !bounds.min) return;
     const chart = $('chart');
     const track = document.querySelector('#chartBody .row.data .gantt-track');
     if (!track) return;
     const ganttStart = track.offsetLeft;
     const stepDays = stepDaysOf(state.step);
     const firstCol = Math.floor(daysBetween(bounds.min, $('offsetInput').value || bounds.min) / stepDays);
     const target = ganttStart + Math.max(0, firstCol - 1) * COL_W - 40;
     chart.scrollLeft = Math.max(0, Math.min(target, chart.scrollWidth - chart.clientWidth));
   }
   ```
   - Вызов в конце `render()`: `ensureBarsVisible(bounds);`
   - Пометить ручной скролл: `$('chart').addEventListener('scroll', () => { if (chart.scrollLeft>4) hScrolledByUser = true; }, {passive:true});`
   - Сброс `hScrolledByUser = false` при смене масштаба/смещения (в обработчиках scale-btn и offsetInput).
