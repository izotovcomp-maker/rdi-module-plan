## Изображение 1 — веб-приложение (макет, browser, file:// .../mock-v1/rdi-module-plan-mock/index.html)

Общее: светлая «бумажная» тема, фон ≈#faf7f0, сверху заголовок «рафик модулей» (обрезано слева, должно быть «График модулей») и серая строка «лакет каркаса (М2): зоны, sticky, вымышленные данные» (тоже обрезано слева — заголовок уехал за левый край).

**Панель инструментов (верх, одна строка, справа):**
- Тумблер-кнопки «Единично» (активна, чёрная) | «Группово»
- Серый бейдж «Изменений: 0»
- Кнопки «Отправить изменения» и «Отменить изменения» (бледные, неактивные)
- Переключатель масштаба: «1Д | 1Н(активна, чёрная) | 2Н…» — правый край обрезан кадром

**Плашка макета** (чуть ниже, желтоватая полоса): «МАКЕТ — данные вымышлены. Портал Битрикс24 не подключён, названия и цифры придуманы. Проверяем каркас: панель и шапки прилипают при прокрутке вниз, колонка названий — при прокрутке вправо.» + кнопка «Сбросить макет».

**Таблица (левая часть):**
- Две одинаковые sticky-шапки одна под другой: «Этап / модуль» (левая колонка) и колонки «З | Рассмотр. | Разработка | К | О | С | Р» — шапка дублируется дважды (выглядит как баг/издержки каркаса M2).
- Строки этапов (серые плашки, с треугольником-стрелкой): «0001-1-ПОДГОТОВИТЕЛЬНАЯ ДОКУМЕНТАЦИЯ» (по КП: 30…), «0001-2-АРХИТЕКТУРНЫЕ РЕШЕНИЯ» (по КП: 15…), «0001-3-КОНСТРУКТИВНЫЕ РЕШЕНИЯ» (по КП: 20…), «0001-4-ИНЖЕНЕРНЫЕ СИСТЕМЫ» (по КП: 25…) — значения КП обрезаны («30_», «15_» и т.п.).
- Строки модулей: «1 · ИИ_01», «2 · ГП_01», «3 · АР_01», «4 · АР_02», «5 · КР_01», «6 · КР_02», «7 · ОВ_03», «8 · СС_07» (номер слева от названия).
- Ячейки модулей: поля-инпуты «З» (число), даты с иконкой календаря (Рассмотрение, Разработка), числа К/О/С, «Р» — просто число. Пример: ИИ_01 → З=5, 07.09.2□, 14.09.2□, К=3, О=1, С=4, Р=8.
- Модуль 4·АР_02 — пустые даты («ДД.ММ.Г»), З/К/О/С = 0, Р = «—» (граничный случай «без дат»).
- Модуль 6·КР_02: 02.11.2□ / 02.11.2□, Р=1 (даты равны).

**Гант (правая часть):** практически пуст — видна только шапка «Август» и одна колонка «26.08» у края; основная область Ганта правее кадра/не отрисована в видимом окне. Полос работ не видно (пользователь, судя по всему, не прокрутил вправо, либо сетка начинается далеко).

**Низ:** слева ряд бледных прямоугольников (похоже на масштабный скроллбар/заготовку легенды), справа тонкий жёлтый горизонтальный скроллбар.

Несоответствия: заголовок страницы обрезан слева; шапка таблицы задвоена; Гант в видимом окне пуст (полосы не видны без прокрутки); колонка «Р» шире остальных; даты во всех ячейках обрезаны («07.09.2□» — не видно последнюю цифру года).

## Изображение 2 — прототип (Excel, лист «Объект такой-то»)

Общее: классический Excel, светло-серая сетка, широкая таблица + Гант из закрашенных ячеек.

**Шапка (строки 7–8):** «Объект такой-то»; блок управления: переключатель «On/Off», красное «Смещение» = -7, кнопка «Отправить», «Шаг» = 6, красное «НАЧ» = 15.07.26.

**Шапка календаря (два уровня):** верх — месяцы под наклоном (Июл 26, Авг 26, Сен 26, Окт 26, Ноя 26, Дек 26, Янв 27, Фев 27); низ — даты с шагом 7 дней: 8, 15, 22, 29, 5, 12, 19, 26, 2, 9, 16, 23, 30, 7, 14, 21, 28, 4, 11, 18, 25, 2, 9, 16, 23, 30, 6, 13, 20, 27, 3, 10, 17, 24.

**Таблица (колонки A–P), строка 9 — шапка с фильтрами:** ID | Модуль | З | Рассм | Разраб | К | О | С | Соглас | Р.
- «З» = 0 у всех строк; «К» = 0 у всех; «О» и «С» — числа (0–66); «Соглас» — дата завершения; «Р» — число (0–60).
- Модули — коды вида «0001-1-ИИ_1.1-Подготовка к ППО», «0001-2-1-ПД_2.1-СП», «0001-3-ГГЭ_4.1-Вся документация», «0001-4-ТЧКД_5.1-Разработка ТЧКД» и т.п.; id 146–188 (чётные).
- Даты Рассм/Разраб в формате ДД.ММ.ГГ (15.07.26 … 29.01.27). Голубая заливка чередуется группами строк (визуальная группировка по разделам, напр. строки 17–25 — одна группа «0001-2-1-ПД_…»).
- Пример строки 10: id 146, 0001-1-ИИ_1.1-Подготовка к ППО, З=0, Рассм=15.07.26, Разраб=21.07.26, К=0, О=0, С=0, Соглас=21.07.26, Р=6.

**Гант (правее, колонки O–BH):** полосы из чёрных квадратов в ячейках — одна колонка = один шаг (6/7 дней?); у строки: короткая чёрная полоса (работы), затем пунктирные чёрточки «—» в отдельных ячейках (ожидание/согласование — вторичный акцент). Например строка 12 (id 150): три чёрных квадрата подряд + «— —»; строка 18 (id 162): ~10 квадратов + «— —». Полосы у разных строк начинаются в разных колонках, сдвигаясь вправо по календарю.

**Сравнение с веб-приложением (Изображение 1):**
- Состав колонок совпадает по смыслу (даты Рассм/Разраб, длительности, «Р»), но в прототипе есть отдельная колонка «Соглас» (дата согласования) — в веб-версии её нет, только «С» (дни).
- В прототипе календарь с наклонными подписями месяцев и датами по шагам; в веб-версии шапка календаря в кадре почти пуста.
- В прототипе полосы Ганта рисуются в ячейках сетки сразу; в веб-версии в видимой области полос нет.
- В прототипе есть «Смещение» (число −7) и «Шаг» (6) как числа; в веб-версии — переключатель масштаба и поле-дата.
- Группировка в прототипе — чередующейся голубой заливкой; в веб-версии — серыми плашками этапов со сворачиванием.
