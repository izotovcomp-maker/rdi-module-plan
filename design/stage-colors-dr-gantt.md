# Дизайн: цвета стадий на Ганте, поле ДР, интервалы от check/create

**Статус:** утверждён пользователем 2026-10-12.
**ТЗ:** колонка ДР `UF_CRM_14_MOD_DAY2_CHECK`, переименование Д-колонок, новые интервалы стадий, палитра плашек на Ганте, пересчёт только на клиенте.

## Проблема
1. Полосы Ганта красятся двумя фиксированными цветами (accent/secondary) — нет привязки к палитре стадий.
2. Нет поля «Дни на Рассмотрение» (`UF_CRM_14_MOD_DAY2_CHECK`) — колонки и логика Рассмотрения не строятся от длительности.
3. Интервалы стадий считались от `dstart` этапа и хранимых дат `runD` — по новому ТЗ якоря только `check`/`create` + длительности.

## Цели
- Колонки: Статус · ДЗ · **ДР (новая)** · Рассмотр. · Разработка · ДК · ДО · ДС · Р (Р — расчётная, не меняется).
- Гант: 6 полос по интервалам ТЗ, цвета — палитра `crm.status.list` (та же, что у плашек статуса).
- В Б24 уходят только 7 полей: 2 даты + 5 длительностей (включая новую ДР). Пересчитанные даты стадий на портал не пишутся (их считает БП портала).

## Интервалы полос (якоря check/create, effModule с правками)

| Полоса | Старт | Финиш | Цвет (код стадии) |
|---|---|---|---|
| Запуск | check−(ДЗ+ДР) | check−ДР | NEW |
| Рассмотрение | check−ДР | check | PREPARATION |
| Разработка | check | create | CLIENT (акцент) |
| Корректировка | create | create+ДК | UC_AJTX21 |
| Ожидание | create+ДК | create+ДК+ДО | UC_PM02XS |
| Согласование | create+ДК+ДО | create+ДК+ДО+ДС | UC_M71TWU |

- Длительность 0/пусто → полоса не рисуется (для всех пяти, включая ДЗ/ДР).
- Нет check или create → полос нет вовсе (запуск от dstart удалён).
- Флаг «Завр/Анну», затемнение завершённых, «Р» = create−check+1 — как сейчас.

## Пустые длительности = 0 (решение пользователя)
При загрузке пустое ДЗ/ДР/ДК/ДО/ДС показывается как 0 и сразу кладётся в правки
(pending) — отправка нормализует нули в Б24 у всех модулей, включая
незапланированные (без дат). Ошибка валидации «Длительность не задана» удаляется;
остаются проверки «число, ≥ 0» и check ≤ create.

## Дополнение 2026-10-12 (живая проверка): два фикса

(days × COL_W/stepDays), минимум 3px-слэб, горизонтальный сдвиг внутри колонки

диапазоном дат; логика — чистая layoutBars() в gantt-logic.js + node-тест.
