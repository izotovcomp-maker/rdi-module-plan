# Дизайн: пачка улучшений UI графика (batch 5)

Дата: 2026-10-12. Утверждено пользователем в чате (ответ «да» на обе секции).

## Проблема

Фича «График модулей» работает и подтверждена живыми проверками. Пользователь
просит пачку из 12 улучшений UX: закрепление колонок, формат ввода дат,
режимы сворачивания этапов и правки, групповой ввод над колонками,
авто-смещение Ганта, выравнивание пульта, выгрузка в PDF.

## Цели

1. Закрепление всего левого блока таблицы (Название → Р) при горизонтальном скролле.
2. Заголовок колонки Статус → «Ст» (тултип остаётся, без скобок про цвета Б24).
3. Парсер дат принимает `ДД.ММ.ГГ`, `ДД-ММ-ГГ`, `ДДММГГ`, `ДД.ММ`, `ДД-ММ`, `ДДММ`
   (неполные — с текущим годом). Значение в поле всегда рендерится `ДД.ММ.ГГ`.
4. Поля дат Рассмотрение/Разработка: 84px → 68px.
5. Этапная строка: убрать «по КП:», оставить дату шрифтом редактируемых полей, полужирным.
6. Тумблер этапов: Свернуть все / Развернуть все / Свободно (по умолчанию Свободно).
7. Режимы правки: «👁 Чтение» (по умолчанию, поля readonly без рамок),
   «1️⃣ Единично», «🔟 Группа» (переименовано из «Группово»).
8. Панель группового ввода — строкой общей сетки, поля над своими столбцами;
   даты подчиняются п.3.
9. Кнопки `🔄 Отправить изменения`, `❎ Отменить изменения`, выровненные шрифты.
10. Смещение при загрузке и каждом переключении масштаба = самая ранняя дата − шаг
    масштаба (ручной ввод живёт до следующего переключения масштаба/перезагрузки).
11. Единые шрифты/высоты пульта (кнопки и инпуты: 13px mono, высота 28px).
12. Кнопка «📝 в pdf»: window.print() с print-CSS `@page A4 landscape`;
    пользователь в диалоге выбирает «Сохранить как PDF».

## Не-цели

- Серверный PDF, библиотеки (vanilla без bundler), сохранение настроек вида
  между сессиями, изменения бэка (`graph.php`) и контракта сохранения (7 полей).

## Подход

Фронт-бэг: `www/template.html`, `www/js/app.js`, `www/js/gantt-logic.js`,
`www/css/app.css`. Чистые функции (парсер дат, дефолт-смещение) — в
`gantt-logic.js`, покрываются node-тестами в /tmp/kilo/.

- **1**: CSS sticky-каскад на колонки таблицы (левые offset'ы), в group-режиме
  сдвиг на ширину чекбокс-колонки. Ширины колонок уже в `--grid-cols`.
- **3**: расширение `parseDyy` (regexp нескольких форматов, проверка валидности
  даты; для 2-компонентных — текущий год). Плейсхолдер `дд.мм.гг`, title с примерами.
- **6**: состояние `collapseMode` ('free'|'all'|'none') поверх `collapsed`;
  кнопки тулбара.
- **7.1**: `state.mode = 'read'` по умолчанию; режим-кнопки в template.html;
  CSS `.read-mode .cell-input` без рамок, readonly.
- **8**: `#groupEntry` рендерится строкой сетки `--grid-cols` внутри chartInner
  над шапкой; поля `gw-*` те же.
- **10**: в обработчиках scale-btn и в render() при загрузке — всегда
  `defaultOffsetIso(bounds.min, step)`; ручной ввод в `offsetInput` работает как
  переопределение до следующего переключения масштаба.
- **12**: класс `print-mode` на body при print (media query), скрыть toolbar/
  панели, снять sticky, показать всё; `@page { size: A4 landscape; margin: 10mm }`.

Альтернативы, отвергнутые: PDF сразу файлом в JS (нужны библиотеки/canvas —
против правил проекта); «Ручное важнее» для смещения (пользователь выбрал
всегда пересчитывать); закрепление только столбца «Р» (пользователь выбрал
весь блок).

## Контракты

- `parseDyy('300826')` → `'2026-08-30'`; `parseDyy('30-08-26')` → ISO;
  `parseDyy('3008')` → `'2026-08-30'` (текущий год); невалидные → null.
- `defaultOffsetIso(minIso, step)` — без изменений, вызывается всегда при
  load и switch scale.
- Сохранение в Б24 не меняется.

## Проверка

- Node-тесты (расширить /tmp/kilo/test-gantt.js или новый): все форматы дат,
  валидные/невалидные, текущий год; defaultOffset для 1д/1н/2н.
- Ручная проверка в браузере (макет/local): sticky колонок при скролле,
  режимы чтения/правки, сворачивание, групповой ввод над колонками,
  выравнивание пульта, печать → предпросмотр PDF A4 landscape.
- Деплой + живая проверка пользователем (Дебаг-кнопка не нужна — фича чисто фронт).
